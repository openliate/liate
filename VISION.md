# Welcome to OpenLiate

> Liate — The Open Source Runtime for Serverless AI Agents.

---

### The Vision

We are moving from traditional code to agentic systems:

- **1972:** `printf("Hello, World\n");` → Procedural
- **1995:** `class HelloWorld { ... }` → Object-Oriented
- **2026:** `class HelloAgent extends LiateAgent { }` → Agentic OOP

**Class is an Agent. Agent is an API (LAPI/v1).**  
From zero-cost local silicon to serverless cloud.

---

### Core Principles

1. **Class-as-an-Agent**: Declarative, object-oriented agent architecture.
2. **Agent-is-an-API**: Native self-hosting endpoints (`LAPI/v1`).
3. **Local-to-Cloud**: Seamless execution from on-device models to edge serverless workers.
